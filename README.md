# Predictive_Analysis_for_Loan_Defaults

1.Built an end-to-end ML pipeline using RandomForestClassifier, GridSearchCV, and Streamlit to predict loan default risk with optimized accuracy.

2.Engineered features using correlation analysis, handled missing data, and applied preprocessing via ColumnTransformer for both numerical and categorical variables.

3.Deployed a user-friendly web app with Streamlit for real-time prediction from user inputs using a trained and serialized model (.pkl file).
